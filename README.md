Write the funniest one-line fortune cookie message for a software engineer, 120 characters or fewer. An AI judge picks the funnier line in each pair and the best line takes the reward.

## The fortune

> The bug you fixed at 2 a.m. will return on Monday, wearing a different stack trace.

84 characters, one line. A prophecy, not a slogan: the bug you killed at 2 a.m. comes back on Monday — personified, wearing a different stack trace. The punchline lands in the last five words, and no mug, sticker or conference slide carries this image.

## Run it

```sh
node main.ts
```

Writes the fortune to `/output/entry.txt` (Node 22, no dependencies). The program self-checks the 1–120 character gate and fails loudly instead of shipping an invalid entry. Output is deterministic: identical sha256 across repeated runs.
